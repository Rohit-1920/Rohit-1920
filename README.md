<div align="center">

<img src="https://img.shields.io/badge/100%25-Long--lived_AWS_credentials_eliminated-DC2626?style=for-the-badge&labelColor=0F172A" alt="Long-lived AWS credentials eliminated"/>

- **Trust:** policy restricted to one repository and one branch
- **Delivery:** static build synced to private S3 and served through CloudFront with OAC
- **Origin:** ALB as the API origin, with HTTPS-only access
